### 💻 What I've Been Building

#### 🏥 Event-Driven Healthcare Ecosystem
A distributed backend platform built to mirror production-grade architecture. 
* **The Architecture:** 5 independent Spring Boot microservices interacting seamlessly.
* **The Tech:** Low-latency sync communication via **gRPC**, combined with async messaging using **Apache Kafka**.
* **The Resilience:** Designed to handle failures gracefully using **Resilience4j** circuit breakers and **Redis** rate limiting.

#### 🎓 University Records Management API
A robust RESTful service focused on strict data contracts and optimized query execution.
* Leveraged **Spring Data JPA Specifications** to handle large-scale data retrievals efficiently.
* Ensured high reliability by covering service and repository logic with comprehensive **JUnit 5** tests.
